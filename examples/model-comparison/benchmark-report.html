Methodology and honesty

What this report proves—and what it does not

ExecutionAnonymous Apex ran successfully in mydevorg. One Case and one Lead scenario were evaluated once by each provider.
TimingWall-clock time was measured in Apex immediately around each provider invocation. It includes network and service latency visible to Salesforce.
Task parityEach provider received the same semantic state, instructions, choices, and rubric. Wire formats differ because Jev accepts native structured questions while the generative API accepts a text prompt.
Token sourceToken counts are the values reported by each provider. Tokenizers can differ, so counts measure actual reported consumption—not tokenizer-identical text.
Side effectsThe benchmark used synthetic data, executed zero SOQL queries and zero DML, and did not change record ownership, Rating, Priority, escalation, or Tasks.
Statistical scopeThis is a transparent live snapshot, not a statistically significant load test. Latency and generated probabilities may vary across runs, regions, load, models, and org configuration.

Percentages and multipliers in this document are derived from the captured values and rounded to one decimal place. Score scales differ: Jev returned zero-based scores from 0–3; the generated comparison returned labels 1–4. The report normalizes each score against its own maximum when comparing position on the rubric.
